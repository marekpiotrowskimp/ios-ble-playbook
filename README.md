# ios-ble-playbook

Practical material on **Bluetooth Low Energy on iOS** (Core Bluetooth).

| Directory | Contents |
|---|---|
| [`guide/BLE_iOS_Guide.md`](guide/BLE_iOS_Guide.md) | A concise guide (in Polish): CBCentralManager, scanning and discovery, connecting, GATT services and characteristics, read/write/notifications, CBPeripheralManager, background modes, state restoration, best practices and gotchas, quick reference |
| [`guide/BLESample/`](guide/BLESample/) | Sample app accompanying the guide |
| [`ble-architecture/`](ble-architecture/) | A BLE app architecture built around an **event bus** (Combine): communication layer, event handlers, device models |

Open the corresponding `.xcodeproj` in Xcode.
